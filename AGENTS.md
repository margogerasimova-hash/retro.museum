# Спільні правила сайту Software and Computer Museum

Ці правила діють для всіх, хто працює із сайтом: людей і ШІ-агентів.

1. Сайт статичний: HTML, CSS і JavaScript без зовнішніх бібліотек і сервісів.
2. Усі шляхи до сторінок, стилів, скриптів, зображень і даних — відносні.
3. Основний текст — не менше 18 пікселів. Контраст тексту й фону — за WCAG 2.1 рівня AA: не менше 4.5:1 для звичайного тексту і 3:1 для великого.
4. Працюй лише в окремій гілці. У гілці main нічого не змінюй: жодних комітів, злиттів чи push напряму в main.
5. У файлах сайту не має бути персональних даних.
